# Distark template demo art

Two tiny demo fighters used by the `versus` template examples in
[`jtoy/distark_video_templates`](https://github.com/jtoy/distark_video_templates)
(`versus/api.yml`), because a template's `file` params have to be a public URL.

| file | what it proves |
|---|---|
| `germ.png` | flat white background: the run cuts it out from the corners |
| `muncher.png` | real transparency: the run uses it as-is |

Both are drawn by `versus/tools/make_demo_fighters.mjs` in that repo, so they can be
regenerated and kept in sync. Same art, same licence, no attribution needed.
